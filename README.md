# Нейро — сайт с нейросетью, обученной с нуля

Настоящие (маленькие!) нейроны без API-ключей и без облака: двухслойный трансформер
(мини-GPT), обученный с нуля своим кодом на numpy, с инференсом на чистом JavaScript
прямо в браузере.

## Структура

```
generate_corpus.py   генератор обучающего корпуса (4120 пар вопрос-ответ)
train.py             tokenize → трансформер forward → ручной backprop → Adam → экспорт model.json
train.log            лог обучения (gradient check, кривая loss)
data/corpus.txt      сгенерированный датасет
site/                сам сайт: index.html + style.css + app.js + model.json
```

## Как обучали

- Word-level токенизатор (свой), словарь ~700 токенов.
- Модель: d_model=96, 3 головы внимания, FFN=384, 2 слоя, контекст 44 токена, tied embeddings.
- Свой forward и свой backprop на numpy (проверены численным сравнением с конечными разностями — 33/33 совпадений).
- Adam, warmup + cosine decay, 8000 шагов, ~35 минут на CPU.
- Loss считается только на токенах ответа — модель учится отвечать, а не повторять вопрос.
- Финальный loss ≈ 0.0000.

## Как запустить сайт

Обычный статический сайт: 

```bash
cd site && python3 -m http.server 8080
# открыть http://localhost:8080
```

Если http-сервер неудобен — можно просто открыть site/index.html двойным кликом: браузеры блокируют fetch(model.json) для file://, поэтому в этом случае веса автоматически подхватятся из model.js (обычный script-тег). Если не сработает и это — откройте страницу в Firefox или Safari.

## Что умеет Нейро

Приветствия, рассказ о себе, арифметика 0–40 (сложение, вычитание до 20, таблица умножения),
сравнение чисел, десятки фактов, честные «не знаю» за пределами обучения.

## Ограничения

Это крошечная модель — «сознание» в строгом смысле никто не воспроизведёт в браузере,
но это настоящий нейросетевой интеллект: ответы генерируются предсказанием токенов
по обученным весам с температурой и top-k сэмплированием, а не поиском по шаблонам.
